Als je het sudo -l commando gaat doen You can zien dat we /usr/sbin/needrestart kunnen gebruiken voor commando als root uittevoeren. Als je dan het help commando gaat gebruiken You can zien dat als je het -c parameter gaat gebruiken You can een config file gaan restarten waardoor dat als je de root.txt file kiest zal je de root flag te zien krijgen.
