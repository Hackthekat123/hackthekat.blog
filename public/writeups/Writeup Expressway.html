Machine Overview

Expressway is a Medium difficulty Linux machine that exposes an IPsec/IKE VPN service on UDP port 500. The attack path involves fingerprinting the IKE implementation, capturing and cracking the pre-shared key (PSK), and using the recovered credentials for SSH access. Privilege escalation is achieved through CVE-2025-32463, a local privilege escalation vulnerability.

Foothold: IPsec/IKE VPN Exploitation

Understanding IPsec

IPsec (Internet Protocol Security) is a protocol suite for securing IP communications through authentication and encryption. It operates in two phases: Phase 1 establishes a secure channel and verifies identity using credentials (username/password or certificates), while Phase 2 configures the parameters for securing data using ESP (Encapsulating Security Payload).

IKE Fingerprinting

Since the detailed port scan was taking too long, I directly probed port 500 using the ike-scan tool. This tool sends IKE Phase 1 proposals to discover the VPN gateway's supported transforms and authentication methods.

Through research, I found CVE-2025-32463, a local privilege escalation vulnerability affecting this system. The exploit is available at: https://github.com/kh4sh3i/CVE-2025-32463.

I download the exploit script to the target, set execute permissions, and run it. The exploit successfully escalates privileges to root.

ike@expressway:~$ chmod +x exploit.sh
ike@expressway:~$ ./exploit.sh
